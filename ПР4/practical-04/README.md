# Практична робота №3

Проєкт продовжує сайт розкладу групи П-425.

## Файли
- `index.html` — основна сторінка з розкладом.
- `login.html` — форма входу.
- `register.html` — форма реєстрації.
- `news-form.html` — форма додавання новини.

## Методи
- Вхід: POST `/login`, тому що передаються облікові дані.
- Реєстрація: POST `/register`, тому що створюється обліковий запис.
- Додавання новини: POST `/news`, тому що створюється новий запис.

Серверне надсилання та JavaScript-валідація на цьому етапі не реалізуються.

## Поля форми новини
| Поле | Тип | Обов'язкове | Обмеження |
|---|---|---|---|
| Назва | text | так | 3–80 символів |
| Текст | textarea | так | 10–1000 символів |
| Категорія | select | так | один варіант |
| Дата | date | так | коректна дата |
| Пріоритет | number | так | 1–5 |
| Видимість | radio | так | один варіант |
| Додаткові параметри | checkbox | ні | незалежні опції |

Усі поля мають `id`, `name` та видимі `label`. Для груп radio/checkbox використані `fieldset` і `legend`. Для паролів задано `autocomplete`.
