# Практична робота: модульний сервіс новин

Проєкт продовжує сайт коледжу БФКПЕП. Для практичної роботи основною сутністю обрано новину. Модуль містить демонстраційний набір даних, нормалізацію та валідацію, пошук і фільтри, перетворення й агрегати, незмінювані CRUD-функції та self-checks.

## Структура

- `scripts/data.js` — 8 демонстраційних новин без персональних даних.
- `scripts/news-service.js` — функції роботи з новинами.
- `scripts/news-storage.js` — завантаження початкового набору та збереження змін у браузері.
- `scripts/news-page.js` — показ, фільтрація, сортування й видалення на головній сторінці.
- `scripts/news-form-page.js` — створення та редагування через HTML-форму.
- `scripts/news-service.test.js` — автоматизовані self-checks і консольний звіт.
- `package.json` — налаштування ES Modules і команда запуску.

## Запуск

Потрібен Node.js. У корені проєкту виконайте:

```sh
npm run check
```

Скрипт друкує результат кожної перевірки та загальну кількість успішних перевірок. Код сервісу також можна імпортувати як ES Module.

Для роботи сторінок із браузерними ES Modules запустіть локальний HTTP-сервер з кореня проєкту командою `npm run serve`, а потім відкрийте `http://localhost:4173`. Не відкривайте `index.html` як `file://`: браузер блокує ES-модулі через CORS. Початкові новини завантажуються з `scripts/data.js`; створені та змінені записи зберігаються у `localStorage` цього браузера.

На `index.html` список новин має пошук, фільтри за категорією та видимістю, сортування, редагування й видалення. Форма `news-form.html` створює новини та відкриває на редагування запис за параметром `?id=...`. Збереження форми повертає до списку. Це клієнтська реалізація: серверного API немає.

## Контракт запису

Об'єкт новини має поля: `id` (додатне ціле число), `title` (3–80 символів), `text` (10–1000 символів), `category` (`оголошення`, `подія` або `навчання`), `date` (реальна календарна дата `РРРР-ММ-ДД`), `priority` (ціле число 1–5), `isVisible` та `isPinned` (boolean).

## Контракт функцій

- `normalizeTitle(value)` обрізає краї та зводить послідовності пробілів до одного; не-рядок дає порожній рядок.
- `normalizeCategory(value)` обрізає пробіли та нормалізує регістр; не-рядок дає порожній рядок.
- `validateNews(input)` повертає `{ isValid, errors }`; помилки згруповані за назвами полів, повідомлення не друкуються.
- `createNews(input, id)` нормалізує назву й категорію, перевіряє весь запис і ID; некоректні дані призводять до `TypeError`.
- `findNewsById(items, id)`, `filterByCategory(items, category)`, `searchNews(items, query)` та `filterNews(items, criteria)` приймають масив аргументом. Комбінований фільтр підтримує `category` і `isVisible`.
- `hasVisiblePinnedNews(items)` перевіряє через `some`, чи є видима закріплена новина.
- `toNewsCards(items)` повертає короткі об'єкти для списку; `toNewsLabels(items)` формує текстові підписи.
- `summarizeNews(items)` через `reduce` повертає кількість, кількість записів за категоріями, кількість видимих новин і суму пріоритетів. Для порожнього масиву значення лічильників дорівнюють нулю. `averagePriority(items)` повертає 0 для порожнього масиву.
- `sortByTitle(items)` і `sortByDate(items)` повертають нові відсортовані масиви, початковий масив не змінюють.
- `addNews(items, newItem)` повертає новий масив; вимагає валідний запис і унікальний ID, інакше кидає помилку.
- `updateNews(items, itemId, changes)` повертає новий масив і валідований запис. ID завжди зберігається незмінним, навіть якщо його передано в `changes`. Якщо ID не знайдено, повертається початковий масив. Некоректне оновлення кидає `TypeError`.
- `removeNews(items, itemId)` повертає новий масив без запису. Якщо ID не знайдено, повертається новий масив з тими самими записами.

## Попередні сторінки сайту

- `index.html` — інформаційна сторінка з розкладом.
- `login.html` — форма входу.
- `register.html` — форма реєстрації.
- `news-form.html` — форма додавання новини.
